# myQuery

## 类似jQuery，Zepto

## 例子
[dom操作](!https://listen80.github.io/myQuery/examples/dom.html)  
[event监听](!https://listen80.github.io/myQuery/examples/dom.html)  

## dom 操作
```js
$('div').css({ backgroundColor: 'red' })
```

## 事件 监听
```js
$('div').on('click', (e) => { console.log(e) })
```

## ajax
```js
$.ajax({ url: '' })
```
